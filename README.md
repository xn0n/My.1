# My — учебная лаборатория C++/CLI

**Алгоритмы и графика в одном Windows Forms приложении.**

Учебный desktop-проект, объединяющий упражнения по сортировке, рекурсии, графикам, геометрическим фигурам и лабиринту. Интерфейс написан на C++/CLI: обычный C++ используется вместе с формами и графическими компонентами .NET Framework.

`C++/CLI` · `Windows Forms` · `.NET Framework 4.7.2` · `Visual Studio 2022`

## Что можно изучить

| Исходники | Тема |
| --- | --- |
| `MyForm.h`, `MyForm.cpp` | Главное окно, меню и обработчики учебных заданий |
| `Recursion.h`, `Recursion.cpp` | Рекурсивные вычисления и вспомогательные операции |
| `Graph.h`, `Graph.cpp` | Отображение графиков через WinForms Chart |
| `Draw.h`, `Draw.cpp` | Рисование фигур, координаты, заливка и контур |
| `Classes.h`, `MyClasses.cpp` | Работа с классами и объектами |
| `Maze.h`, `Maze.cpp` | Представление лабиринта и обработка клавиатуры |
| `Input.h`, `Table.h` | Окна ввода и табличного представления |

Репозиторий сохраняет учебную структуру и историю изменений. Он полезен как набор примеров связи алгоритмов с графическим интерфейсом; это не универсальная библиотека алгоритмов.

## Подготовка и сборка

Нужна Windows и **Visual Studio 2022** со следующими компонентами:

- Desktop development with C++;
- MSVC **v143** и поддержка **C++/CLI** для этого toolset;
- Windows SDK 10;
- .NET Framework **4.7.2 Targeting Pack**.

Откройте `My.sln`, выберите `Debug | x64` и выполните Build Solution, затем запустите приложение. В solution также предусмотрены Win32 и Release.

Из Developer PowerShell for Visual Studio:

```powershell
msbuild My.sln /m /p:Configuration=Debug /p:Platform=x64
```

## Особенности исходников

Некоторые файлы с русским интерфейсом используют **Windows-1251**. Их кодировка сохранена при подготовке публичного репозитория; открывайте файлы в соответствующей кодировке и избегайте случайного массового преобразования.

`MyForm.resx` содержит встроенные изображения формул, связанные с формой. Копировать локальные build-каталоги и настройки Visual Studio для запуска не требуется.
